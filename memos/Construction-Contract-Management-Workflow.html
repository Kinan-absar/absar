Main Functions - English
Function Purpose Main Users
Contracts Create and manage client contracts or subcontracts, including project, partner, dates, contract value, retention, advance, VAT, and accounting setup. Internal Users
BOQ Enter BOQ lines with item code, description, unit of measure, contract quantity, unit rate, and original amount. Internal Users
Measurements Create measurements from BOQ lines, enter current work by quantity or percentage, attach files, and submit for review. Internal Users / Portal Users
IPCs Create and review IPCs from approved measurements, calculate certified value, retention, advance recovery, VAT, deductions, and net amount. Internal Users / Authorized Viewers
Variations Create variation requests for quantity increase, quantity decrease, new items, omitted items, or rate changes. Internal Users / Portal Users
Access Control Limit visibility for portal users and internal users by assigning allowed employees on each contract. Internal Users / System

الوظيفة الغرض المستخدمون
العقود إنشاء وإدارة عقود العملاء أو عقود المقاولين من الباطن، بما يشمل المشروع، الشريك، التواريخ، قيمة العقد، الاستبقاء، الدفعة المقدمة، الضريبة، والإعدادات المحاسبية. المستخدمون الداخليون

القياسات إنشاء القياسات من بنود جدول الكميات، وإدخال الأعمال الحالية بالكمية أو النسبة، وإرفاق الملفات، ثم الإرسال للمراجعة. المستخدمون الداخليون / مستخدمو البوابة

Process Steps / خطوات العملية

Internal User Workflow
Step Action Responsible
1 Create the construction contract and select whether it is a client contract or subcontract. Internal User
2 Fill project, partner, company, scope, start/end dates, original amount, retention %, advance %, VAT %, and payment terms. Internal User
3 Add BOQ lines with item code, description, UOM, contract quantity, and unit rate. Internal User
4 Assign portal employees and/or internal employees if visibility restriction is required. Internal User
5 Move the contract through review, approval, activation, completion, closure, or cancellation as required. Internal User / Approver
6 Create measurements, check submitted measurements, approve or reject them, and print reports. Internal User / Approver
7 Create IPCs from approved measurements, approve IPCs, and create invoice or bill when applicable. Internal User / Accounting
سير عمل المستخدم الداخلي
الخطوة الإجراء المسؤول
1 إنشاء عقد الإنشاءات وتحديد ما إذا كان عقد عميل أو عقد مقاول من الباطن. المستخدم الداخلي
2 تعبئة المشروع، الشريك، الشركة، نطاق العمل، تواريخ البداية والنهاية، القيمة الأصلية، نسبة الاستبقاء، نسبة الدفعة المقدمة، الضريبة، وشروط الدفع. المستخدم الداخلي
3 إضافة بنود جدول الكميات مع كود البند، الوصف، وحدة القياس، كمية العقد، وسعر الوحدة. المستخدم الداخلي
4 تحديد موظفي البوابة و/أو الموظفين الداخليين إذا كان تقييد الظهور مطلوباً. المستخدم الداخلي
5 نقل العقد بين حالات المراجعة والاعتماد والتفعيل والإكمال والإغلاق أو الإلغاء حسب الحاجة. المستخدم الداخلي / المعتمد
6 إنشاء القياسات، فحص القياسات المقدمة، اعتمادها أو رفضها، وطباعة التقارير. المستخدم الداخلي / المعتمد
7 إنشاء شهادات الدفع من القياسات المعتمدة، اعتماد الشهادات، وإنشاء فاتورة عميل أو فاتورة مورد عند الحاجة. المستخدم الداخلي / المحاسبة
Portal User Workflow
Step Action Responsible
1 Portal user logs in and opens the Construction section from the portal. Portal User
2 User views only assigned contracts and related records. System
3 User opens contract details, financial summary, BOQ progress, IPCs, measurements, and variations. Portal User
4 User creates measurements, selects contract and period, enters quantity or percentage, attaches files, and submits for approval. Portal User
5 User creates variation requests when contract changes are needed and submits them for approval. Portal User
6 User prints or downloads available contract, measurement, IPC, and variation reports. Portal User
سير عمل مستخدم البوابة
الخطوة الإجراء المسؤول
1 يقوم مستخدم البوابة بتسجيل الدخول وفتح قسم الإنشاءات من البوابة. مستخدم البوابة
2 يشاهد المستخدم فقط العقود والسجلات المرتبطة المخصصة له. النظام
3 يفتح المستخدم تفاصيل العقد والملخص المالي وتقدم بنود جدول الكميات والقياسات وشهادات الدفع والأوامر التغييرية. مستخدم البوابة
4 ينشئ المستخدم القياسات، ويحدد العقد والفترة، ويدخل الكمية أو النسبة، ويرفق الملفات، ثم يرسلها للاعتماد. مستخدم البوابة
5 ينشئ المستخدم طلب أمر تغييري عند الحاجة إلى تعديل في العقد، ثم يرسله للاعتماد. مستخدم البوابة
6 يطبع أو ينزل المستخدم تقارير العقود والقياسات وشهادات الدفع والأوامر التغييرية المتاحة. مستخدم البوابة

Statuses & Reports / الحالات والتقارير

Document Statuses / Result
Contract Draft → Under Review → Approved → Active → Completed → Closed / Cancelled.
Measurement Draft → Submitted → Checked → Approved / Rejected. Approved measurements update contract progress.
IPC Draft → Under Review → Approved → Done / Cancelled. Approved IPCs can create invoice or bill.
Variation Draft → Submitted → Approved / Rejected. Approved variations update revised BOQ quantities and amounts.
Reports Contract, Measurement, IPC, Variation, Advance, and Retention Release reports can be printed.
المستند الحالات / النتيجة
العقد مسودة ← قيد المراجعة ← معتمد ← نشط ← مكتمل ← مغلق / ملغي.
القياس مسودة ← مقدم ← تم التحقق ← معتمد / مرفوض. القياسات المعتمدة تحدث تقدم العقد.
شهادة الدفع مسودة ← قيد المراجعة ← معتمد ← منتهي / ملغي. شهادات الدفع المعتمدة يمكن إنشاء فاتورة منها.
الأمر التغييري مسودة ← مقدم ← معتمد / مرفوض. الأوامر التغييرية المعتمدة تحدث كميات وقيم جدول الكميات.
التقارير يمكن طباعة تقارير العقد والقياس وشهادة الدفع والأمر التغييري والدفعات المقدمة وإفراج الاستبقاء.
Important: The workflow supports both internal Odoo users and portal users. Portal users only see assigned contracts, while internal visibility can also be restricted to selected employees when required.
مهم: يدعم سير العمل المستخدمين الداخليين في أودو ومستخدمي البوابة. مستخدمو البوابة يشاهدون فقط العقود المخصصة لهم، ويمكن أيضاً تقييد ظهور العقود داخلياً لموظفين محددين عند الحاجة.

Business Rules / قواعد العمل

Measurements can be entered by quantity or percentage.
The system prevents measured cumulative quantity from exceeding the allowed BOQ quantity.
Only approved measurements can be loaded into IPCs.
IPC quantities cannot exceed measured or allowed quantities.
Approved variations update revised BOQ quantities, rates, and contract revised amount.
Accounting setup must be completed before creating invoice or bill from IPC.
يمكن إدخال القياسات بالكمية أو بالنسبة المئوية.
يمنع النظام تجاوز الكمية التراكمية المقاسة للكمية المسموحة في جدول الكميات.
يمكن تحميل القياسات المعتمدة فقط في شهادات الدفع المرحلي.
لا يمكن أن تتجاوز كميات شهادة الدفع الكميات المقاسة أو المسموحة.
الأوامر التغييرية المعتمدة تحدث كميات وأسعار جدول الكميات والقيمة المعدلة للعقد.
يجب استكمال الإعدادات المحاسبية قبل إنشاء فاتورة من شهادة الدفع.
